# Sales Forecasting

This project contains a basic structure for a sales forecasting workflow.

## Folder structure

- `data/` for raw and processed data
- `notebooks/` for exploratory analysis and modeling notebooks
- `src/` for source code
- `models/` for trained model artifacts

## Setup

```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Typical workflow

1. Place data files in `data/`
2. Explore in `notebooks/`
3. Implement logic in `src/`
4. Save trained models in `models/`

## Notes

This is a starter scaffold intended for experimentation and project development.
